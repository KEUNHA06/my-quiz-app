나의 문제풀이 - iPhone 오프라인 웹앱 패키지

구성 파일
- index.html: 문제풀이 앱
- manifest.webmanifest: 홈 화면 설치 설정
- service-worker.js: 앱 파일과 엑셀 라이브러리 캐시
- icon-192.png / icon-512.png: 앱 아이콘

중요한 설치 안내
1. iPhone은 로컬 HTML 파일만으로 PWA를 홈 화면에 설치할 수 없습니다.
2. 이 폴더의 파일을 HTTPS를 지원하는 웹 호스팅에 한 번 올려야 합니다.
3. iPhone Safari에서 해당 HTTPS 주소를 열고, 공유 버튼 > '홈 화면에 추가'를 선택하세요.
4. 앱을 처음 열 때는 인터넷에 연결된 상태로 두어 캐시가 준비되도록 해주세요.
5. 이후 앱을 홈 화면 아이콘으로 열면 기본 문제풀이 기능은 오프라인으로 동작합니다.
6. .xlsx 가져오기는 첫 온라인 실행에서 엑셀 라이브러리가 캐시되어야 합니다. CSV 가져오기는 별도 라이브러리 없이 작동합니다.

데이터
- 문제와 학습 기록은 해당 iPhone의 Safari 웹 저장소에 저장됩니다.
- 웹사이트 데이터 삭제, 브라우저 저장 공간 정리, 다른 기기 사용 시 기록이 사라지거나 공유되지 않을 수 있으니 앱의 학습 통계 메뉴에서 JSON 백업을 정기적으로 저장하세요.
- PC와 iPhone 사이의 자동 동기화는 포함되어 있지 않습니다.

호스팅 예시: GitHub Pages, Cloudflare Pages 등 HTTPS 정적 호스팅.
