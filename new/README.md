# 직무교재 TTS 플레이어

TXT 파일을 기기 내장 음성으로 읽는 GitHub Pages용 PWA입니다.

## 포함 기능
- TXT 파일 선택
- 브라우저 내장 음성 선택 및 읽기 속도 조절
- 재생 / 일시정지 / 정지 / 처음부터
- 텍스트 진행률 탐색
- 30초 앞뒤 이동(텍스트 길이와 읽기 속도 기반의 근사치)
- 브라우저별 로컬 저장소에 읽기 위치 저장
- 서비스 워커를 통한 앱 파일 캐시
- 화면 켜짐 유지 버튼(Screen Wake Lock API 지원 브라우저에서 동작)

## GitHub Pages 배포
1. 저장소 `my-quiz-app`의 `main` 브랜치에서 `tts-player` 폴더를 만듭니다.
2. 이 폴더 안에 `index.html`, `style.css`, `app.js`, `sw.js`, `manifest.json` 파일을 업로드합니다.
3. 커밋 후 다음 주소를 엽니다:
   `https://keunha06.github.io/my-quiz-app/tts-player/`
4. 온라인 상태에서 한 번 열어 앱 파일을 캐시합니다.
5. iPhone Safari에서 공유 버튼 → 홈 화면에 추가를 선택할 수 있습니다.

서비스 워커 등록 코드는 `index.html`에 이미 포함되어 있습니다.

## 제한
- 브라우저 음성 합성은 기기와 브라우저의 음성 목록, 오프라인 음성 설치 여부에 따라 달라집니다.
- 화면 켜짐 유지 버튼은 화면 자동 잠금을 방지하는 기능이며, 화면을 직접 잠근 상태의 재생을 보장하지 않습니다.
- Screen Wake Lock은 iOS 18.4 이상 Safari에서 지원되지만, 기기 상태나 홈 화면 웹앱 등 실행 환경에 따라 요청이 거절되거나 해제될 수 있습니다. 해제되면 버튼을 다시 눌러 주세요.
- 화면 켜짐 유지 중에는 배터리 소모가 늘 수 있습니다.
- iPhone Safari는 화면 잠금/백그라운드에서 브라우저 TTS를 중단할 수 있습니다. 이 기능은 화면이 켜진 상태에서 읽기를 돕습니다.
- 30초 이동은 실제 오디오 타임라인이 아니라 문자 수와 배속을 이용한 근사치입니다.
- 저장 위치는 같은 브라우저의 로컬 저장소에만 남습니다. 다른 기기와 자동 동기화되지 않습니다.
- 현재는 선택한 TXT 내용 자체를 영구 보관하지 않으므로, 브라우저를 다시 열었을 때 파일을 다시 선택해야 할 수 있습니다.
