나의 문제풀이 앱 - 빈칸 채우기 기능 추가 버전

포함 파일
- index.html: 기존 객관식 앱 + 빈칸 채우기
- service-worker.js: 오프라인 캐시(캐시 버전 v2)
- manifest.webmanifest: 홈 화면 설치 설정
- icon-192.png / icon-512.png: 앱 아이콘

GitHub Pages 업데이트 방법
1. GitHub 저장소 keunha06/my-quiz-app 에 접속합니다.
2. 기존 index.html을 새 index.html로 교체하고 Commit changes 합니다.
3. service-worker.js도 새 파일로 교체하고 Commit changes 합니다.
4. manifest.webmanifest와 아이콘 파일은 기존 파일이 있으므로 그대로 두어도 됩니다. 필요하면 함께 업로드할 수 있습니다.
5. iPhone에서 Safari로 https://keunha06.github.io/my-quiz-app/ 을 열고 새로고침합니다. 앱이 이전 버전으로 보이면 앱을 완전히 닫고 Safari에서 사이트를 다시 열어 잠시 기다린 후 홈 화면 아이콘으로 다시 실행합니다.

빈칸 자료 CSV 열 이름
- 필수: 해설 또는 내용
- 선택: 분야, 제목, 키워드
키워드를 지정하면 그 단어가 빈칸 정답으로 사용됩니다. 비워 두면 앱 내부 규칙으로 단어를 자동 선택합니다.

개인정보 및 오프라인 안내
- 자료는 앱 내부에서 처리되고 기기 브라우저 저장소에 보관됩니다. 서버로 업로드하지 않습니다.
- CSV 불러오기와 빈칸 생성은 오프라인에서 동작합니다. XLSX 불러오기는 SheetJS 라이브러리가 캐시된 이후 오프라인에서 동작합니다. 따라서 업데이트 후 최초 1회는 인터넷 연결 상태로 앱을 열어 캐시가 완료되도록 해 주세요.
- 기존 문제 및 학습기록은 같은 브라우저 저장소 키를 사용하므로 보통 유지됩니다. 업데이트 전에는 반드시 기존 앱의 '학습 기록 백업'을 권장합니다.
- 자동 핵심어 선택은 규칙 기반이라 법령상 정답을 보장하지 않습니다. 중요 용어는 CSV의 '키워드' 열에 직접 지정하세요.
