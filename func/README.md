# 컴활 1급 함수 트레이닝

초보자용 함수 학습 앱의 첫 번째 버전입니다.

## 파일
- `index.html`: 앱 본체
- `manifest.json`: 홈 화면 설치 설정
- `sw.js`: 서비스 워커(방문 후 오프라인 캐시)

## GitHub Pages 배포
1. GitHub 저장소에서 `main` 브랜치 아래 새 폴더를 만듭니다. 예: `function-practice`
2. 이 폴더 안에 위 세 파일을 업로드합니다.
3. 저장소의 Settings → Pages에서 GitHub Pages가 활성화되어 있는지 확인합니다.
4. 접속 주소는 `https://사용자이름.github.io/저장소이름/function-practice/` 형태입니다.

## 사용
- 함수 배우기: 개념, 문법, 예제, 구성요소, 직접 입력 연습
- 연습하기: 10개 함수 문제를 한 화면에서 반복
- 오답 복습: 틀린 함수 문제 다시 풀기
- 학습 기록: 완료 함수, 누적 채점, 정답률 확인

학습 기록은 브라우저의 localStorage에 저장됩니다. 다른 기기나 브라우저와 자동 동기화되지 않습니다.
오프라인 사용은 해당 주소에 한 번 접속해 캐시가 저장된 뒤 지원됩니다. iPhone Safari에서는 페이지를 처음 온라인 상태에서 연 뒤 홈 화면에 추가하는 것을 권장합니다.

## 현재 버전의 범위와 한계
이 버전은 함수 원리를 익히는 학습용 앱입니다. 입력한 수식을 실제 Excel 엔진으로 계산하는 프로그램은 아니며, 등록된 정답 수식과 비교해 채점합니다. Excel 2016 기준 함수명/문법을 확인하면서 기출 유형을 추가하는 방식으로 확장할 수 있습니다.
