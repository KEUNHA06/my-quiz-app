# 직무교재 오디오북 (GitHub Pages)

## 포함 기능
- 아이폰/PC 브라우저에서 PDF 파일 선택
- 브라우저 PDF.js로 페이지 텍스트 추출
- 기기 내 한국어 음성 합성(Web Speech API)
- 재생/일시정지/정지, 속도 조절, 페이지 이동
- 북마크, 마지막 페이지 기록
- 서비스 워커가 앱과 PDF.js 라이브러리를 캐시해 첫 온라인 방문 이후 오프라인 이용을 시도

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만들거나 별도 저장소를 엽니다.
2. `index.html`과 `service-worker.js`를 저장소 최상위에 업로드합니다.
3. Settings → Pages에서 `Deploy from a branch`, `main`, `/(root)`를 선택하고 저장합니다.
4. 배포된 HTTPS 주소를 온라인 상태에서 Safari로 엽니다. 페이지가 완전히 로드된 뒤 한 번 새로고침하고, 앱을 다시 열어 오프라인 캐시가 준비됐는지 시험합니다.
5. 아이폰은 Safari 공유 버튼 → 홈 화면에 추가로 설치할 수 있습니다.

## 중요 제약
- PDF 파일 내용은 브라우저에서 읽으며 서버로 업로드하지 않습니다. 파일 자체는 페이지를 닫으면 메모리에서 사라집니다.
- 북마크/이어 읽기 메타데이터는 해당 브라우저의 로컬 저장소에 저장됩니다. Safari와 PC 사이에 자동 동기화되지 않습니다.
- 스캔 이미지형 PDF는 텍스트 추출이 안 됩니다. OCR 기능은 포함하지 않았습니다.
- 오프라인 음성은 iPhone/PC에 해당 언어의 오프라인 음성이 설치되어 있고 브라우저가 이를 제공해야 합니다. iPhone 설정에서 손쉬운 사용/콘텐츠 말하기 또는 음성 관련 설정을 확인하고, 한국어 음성을 다운로드한 뒤 시험하세요. 브라우저/OS 정책상 화면이 꺼지거나 앱이 백그라운드로 가면 재생이 멈출 수 있습니다.
- 첫 실행 시에는 인터넷이 필요해 PDF.js와 앱 캐시를 준비해야 합니다. 오프라인 동작은 기기에서 실제로 시험해야 합니다.
- 이 버전은 PDF.js를 CDN에서 불러오며, 서비스 워커가 이를 캐시하도록 설계했습니다. 기관 보안 정책상 외부 CDN 요청 자체도 금지되는 환경이라면 PDF.js 라이브러리를 저장소에 직접 포함하는 방식으로 바꾸어야 합니다.
