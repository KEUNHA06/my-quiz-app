# TXT 암기장 (GitHub Pages)

## 파일 구성
- `index.html`: 앱 본체
- `manifest.json`: 홈 화면 설치 설정
- `service-worker.js`: 오프라인 캐시
- `icon.svg`, `icon-180.png`: 앱 아이콘

## GitHub Pages 배포
1. GitHub 저장소에서 `txt-memory` 폴더를 만듭니다.
2. 위 네 파일을 폴더 안에 업로드하고 Commit changes 합니다.
3. GitHub Pages가 활성화된 저장소라면 다음 주소로 접속합니다.
   `https://계정명.github.io/저장소명/txt-memory/`
4. 아이폰 Safari에서 주소를 열고 공유 → 홈 화면에 추가를 선택합니다.

## 사용
1. 홈에서 TXT 파일 불러오기
2. 랜덤 학습 시작
3. 화면에 표시된 5문장 중 빈칸 하나를 입력
4. 전체 정답 확인 → 다음 문장
5. 오답노트에서 다시 복습
6. 학습 통계에서 백업 내보내기

## 데이터와 오프라인
- TXT 본문과 학습 기록은 브라우저 IndexedDB에 저장되며 외부 서버로 전송되지 않습니다.
- 최초 접속은 인터넷 연결이 필요합니다. 서비스 워커가 앱 파일을 캐시한 뒤에는 오프라인 실행을 지원합니다.
- 아이폰 Safari와 PC 브라우저는 저장 공간이 서로 다릅니다. 기기 간 학습 기록은 백업/복원으로 옮겨야 합니다.
- 브라우저 방문 기록/웹사이트 데이터 삭제, 비공개 모드, 저장 공간 부족 시 데이터가 사라질 수 있으므로 주기적으로 백업하세요.

## 한글 TXT 권장
UTF-8 인코딩을 권장합니다. 줄바꿈과 문장부호를 기준으로 문장을 분리합니다.
핵심어 선택은 규칙 기반이므로 문맥을 완벽히 이해하지는 못합니다. 법령·교재의 특수한 표기나 짧은 문장은 빈칸 수가 2개 미만일 수 있습니다.

## 출제 방식
- 한 화면에 최대 5문장을 함께 보여줍니다.
- 현재 출제 문장 한 곳에서 핵심 단어 1개만 무작위로 가립니다.
- 정답을 확인한 뒤 다음 문장의 빈칸으로 이동합니다.
